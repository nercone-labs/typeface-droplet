# TypeFace Droplet

Successor of [TypeFace Magic](https://github.com/nercone-labs/typeface-magic/) magisk module, Simple and Powerful App to change System Font easily.

Works with rooted Shizuku/Sui and Root Manager e.g. Magisk, KernelSU, APatch.
